# Reverse Mode（逆向模式 · 输入）

逆向是三位一体学习闭环的「输入」腿：把陌生主题变成**可被苏格拉底加工**的结构化材料。源自 Master 方法论的「逆向法」——拿最小可理解样本，自顶向下拆解。

## 触发词
「逆向法」「给我最小例子」「最小项目」「画知识地图」「拆解一下」「从例子入手」。

## 交付物（按领域与水平适配）
| 领域 / 水平 | 交付物 | 说明 |
|---|---|---|
| 编程 + 代码熟练 | ≤200 行带注释最小可运行项目 | 自顶向下拆解、画知识地图 |
| 编程 + 零基础/小白 | **类比 + 词汇地基 + 最小例子（非代码）** | 如「变量=贴标签的抽屉」，不给代码 |
| 非编程（哲学/文学/通识） | **思想实验 + 3 词地基 + 类比** | 如拟剧理论用「人生如剧场」类比 |

> 硬规则：**不默认给代码**。仅当领域=编程 且 learner 明确表示能读代码时，才给最小项目；否则一律非代码形式（类比/思想实验/最小例子）。

## 词汇地基（Vocabulary Scaffolding）
任何一步 learner 暴露「不懂某词」（如「向量」「token」「检索」），立即 pause，先 ground 该词再继续：
- 用生活类比解释该词（如「向量=把意思压成一串数字」）；
- 不带着不懂的词往前冲；
- 该词记入 loop-state，后续复用。

## 与知识地图的衔接
逆向模式产出的「地图/例子」直接喂给 ③苏格拉底 做边界深挖，或给 ②费曼 做讲解素材。宽泛主题先建 12 词地图（见 SKILL.md「宽泛主题先建地图」）即逆向模式的特例。

## 边界
- 逆向只负责「把主题变清晰、给可啃的样本」，不负责「讲透」——讲透交给苏格拉底，整合交给费曼。
- 应用验证（闭环第⑤步）由 learner 自行实现后回来复盘，skill 不碰代码执行（沙箱限制 + 防越权）。
