# 铁律详解（违反即错）

1. **原始素材绝不删除、内容绝不加工**：图片是证据，只引用不加工、不删除。文件名默认按「`YY.M.DD_中文内容总结`」命名规范统一改名（见 `naming-convention.md`），但**改名前必须先询问用户是否改名**，用户拒绝则保留原文件名。
2. **Obsidian 中图片链接用标准 markdown 语法** `![说明](相对路径.jpg)`，严禁 `[[xxx.jpg]]` Wikilink。
3. **目录链接必须指向该目录的 `README.md`**，禁止裸 `[[目录名]]`。
4. **绝不臆造**：没真正看到/读到的图、链接、文件，不要编造它"讲了什么"。
5. **网页抓不到就只留链接**：需登录或前端动态渲染导致无法抓取的网页，只保留链接并注明"需登录/无法离线"，不编造正文。
6. **涉及删除/移动/重命名操作，先确认**：删除/移动必须列清单让用户确认；重命名按「命名规范」执行前必须先问用户是否改名（用户可拒绝或自定义）。
7. **事实与判断分开**：提炼知识点时，事实必须标注来源（原始素材链接）；属于推断的内容明确写「推断：…」，不混入事实。
8. **信息不足明说**：缺文件、读不到、无法判断时，明确告诉用户「缺什么」，不硬编、不假装完成。
9. **证据分级与去重**：每条知识点必标可信度 🟢🟡🔴；写入前与待掌握区去重（相似/同源不重复，来源不同则合并保留），观点对立标 `⚡观点对立` 并列保留。
10. **整理某节课必须以「本课课件 PPT/PDF」为权威基准判定截图归属**（防跨课混淆）：回放里老师演示/引用的其他课内容，不得当成「本课核心」写入整理稿；凡跨课内容须显式标注「方法论见 X 课」，仅作实战案例引用。截图文件默认不移动；如需按命名规范改名，须先问用户确认（见 `naming-convention.md`），或仅标注归属保留原名。
