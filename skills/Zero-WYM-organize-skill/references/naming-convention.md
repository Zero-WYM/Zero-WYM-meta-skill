# 命名规范

- 课程目录：`YY.MM.DD 第X节 主题`（小写 `skill`，中文冒号）
  - 例：`26.8.10 第四节 skill实战：先找到好用的，再做出自己的`
- 时间线目录：`26.8.10skill实战：先找到好用的，再做出自己的`
- 板块分层：`素材/学习/...`、`资源/学习/...`（可扩展 `1_小说板块`、`3_个人板块`）
- **截图文件（收到截图后统一改名）**：`YY.M.DD_中文内容总结.扩展名`
  - `YY.M.DD` = 所属课程日期（按**内容语义**判定课程，非文件名拍摄时间）；`中文内容总结` = 2–12 汉字概括核心内容。
  - 禁用字符：`/ \ : * ? " < > |` 及换行；同目录重名追加 `-2`/`-3`。
  - **改名前必须先询问用户是否改名，并提供「自定义改名」选项**；用户拒绝则保留原文件名。仅同一目录内 `mv`，不删除、不跨目录移动。
  - **改名后必须回填 wikilink（防死链）**：改名/移动 `.md`/图片/附件后，同步改写全仓库对该文件的 `[[wikilink]]` 与 `![[transclusion]]` 引用（覆盖标准 `[[A]]`、带别名 `[[A|B]]`、嵌入 `![[A]]`、带章节 `[[A#h]]`、带扩展名 `[[A.png]]`），避免死链与 `Folder already exists`。流程：只读扫描出「引用回填预览」清单 → 用户确认 → 批量替换。⚠️ 自动化脚本 `rename_sync.py` 待补（当前手写/逐文件处理）。
