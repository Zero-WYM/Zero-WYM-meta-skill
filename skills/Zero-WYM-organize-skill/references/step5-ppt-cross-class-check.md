# Step 5：截图对照课件 PPT 分清楚归属（防跨课混淆）

**何时必做**：整理某节课的截图（尤其看回放截取、无日期 GUID 命名、或命名按日期但内容可能跨课）时，必须先对照「本课课件 PPT/PDF」判定归属，再写整理稿。这是 8.12「Agent 登场」踩坑后固化的红线（见 `discipline-details.md` 踩坑案例）。

**固定四步法**：

1. **提取本课课件框架**：提取本节课 PPTX/PDF 全文 → 建立「本课真实内容框架」（章节标题/关键词）。
   - PPTX：`python -c "import zipfile,re; z=zipfile.ZipFile(p); [print('\n'.join(t for t in re.findall(r'<a:t>(.*?)</a:t>', z.read(s).decode('utf-8','ignore')) if t.strip())) for s in sorted([n for n in z.namelist() if re.match(r'ppt/slides/slide\d+\.xml$',n)], key=lambda x:int(re.findall(r'(\d+)',x)[0]))]"`
   - PDF：用 Read 读取。
   - 课件路径见各课 `课件/` 目录（如 `26.8.12 第五课 Agent登场：创建第一个能完成任务的AI伙伴/课件/`）。
2. **逐张读截图对照**：对每张截图，对照框架判三类：
   - ✅ **本课核心**：内容匹配本课 PPT 某章节 → 标对应章节。
   - ⚠️ **回放演示·他课内容**：本课回放里老师演示/引用的其他课内容（如 A 课回放演示 B 课的方法论）→ 标「方法论见 X 课」，仅作实战案例引用。
   - ❓ **待确认**：无法确定归属 → 标待确认，不硬编。
3. **产出截图对照表**：在本课目录写 `截图对照表.md`，列 `文件名/短GUID → 画面主题 → 角色（✅/⚠️/❓）`。
4. **整理稿只写本课核心**：✅ 内容进整理稿正文；⚠️ 他课内容在整理稿中仅作「实战案例」引用并标注归属，**不展开成方法论、不当本课核心**。

**补充**：命名按日期归课的截图（如 `Screenshot_2026-08-06*`）归属一般可信，但仍需逐张核对是否真匹配本课 PPT，防回放演示的他课内容混入。多个 Agent 并行处理不同课时，各自只写本课 `截图对照表.md`，**不要改素材池 README.md**（避免并发写冲突）。截图文件默认留在原目录不移动；如需按命名规范改名，须先问用户确认（见 `naming-convention.md`）。
